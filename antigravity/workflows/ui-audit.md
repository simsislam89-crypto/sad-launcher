> **Sad Launcher (приоритет над всем ниже).** Эти правила пришли из другого проекта (eRoot). Для Sad Launcher: цели по умолчанию —
> `site/index.html`, `site/styles.css`, `site/app.js` и тексты интерфейса лаунчера в `src/views/*.rs`, `src/app.rs` (Rust, egui).
> Игнорируй упоминания Telegram, Mini App, бота, `i18n.js`, `copy.js`, `texts.py`. Язык интерфейса — только русский.
> Тема — чёрно-белая, стеклянные (полупрозрачные) элементы, без цветных акцентов. Кнопка главного действия — глагол («Добавить», «Установить»).

Проведи аудит интерфейса (`$ARGUMENTS`, по умолчанию `site/index.html`, `site/pages/*.html`, `site/css/styles.css`, `site/js/*.js`). Отвечай по-русски. Сначала отчёт, правки — только по подтверждению.

Ищи и фиксируй в отчёте (`файл:строка`):

## Клише генеративного ИИ
- Градиенты на фоне, в кнопках и тексте без смысловой причины. Допустимы только по правилам проекта из памяти (см. `design-no-flat-fills`): стекло и блик по канту, графики без градиентов.
- Неоновое свечение, фиолетово-розовые размытия, большие цветные тени, «облака» света.
- Перегруженные тени: несколько слоёв `box-shadow` с большими радиусами.
- Чрезмерные скругления и «пилюли» там, где нужны строгие углы (графики — `rx=0`).

## Эмодзи и иконки
- Любые эмодзи в функциональном интерфейсе — заменить на SVG-иконки Lucide или Feather в одном линейном стиле (`stroke-width` 1.5–2, `currentColor`).
- В Telegram-ботовых текстах эмодзи допустимы в меру (см. `bot-and-site-ux-preferences`); этот пункт относится к сайту и Mini App.

## Контраст и текст
- Вторичный текст: проверить читаемость на фоне; матовый пепельный не должен падать ниже 4.5:1.
- Размеры: основной текст не меньше 15 px на мобильном.
- Заголовки и подписи — один гротеск, без декоративных шрифтов.

## Отступы и ритм
- Отступы кратны 8 px, внутри карточек — одинаковые.
- Выравнивание по одной левой линии, без смещений на 1–3 px.
- Разделители — 1px полупрозрачные линии в тон фону, без тяжёлых рамок.

## Состояния
- У кнопок и карточек есть hover, active, focus-visible и disabled.
- Анимации не дёргаются; есть `prefers-reduced-motion`.
