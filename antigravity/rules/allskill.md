# allskill — протокол Sad Launcher (always on)

Ты работаешь над проектом Sad Launcher (Rust/egui-лаунчер Minecraft + статический сайт в `site/`).
Полная версия протокола — `.agent/skills/allskill/SKILL.md`; здесь короткая обязательная выжимка. Эти пункты — действия, не справка.

## 0. Перед первой правкой
1. Прочитай `RRR.md` целиком (история, архитектура, грабли). Затем `SKILLS.md` и `ANTIGRAVITY.md`.
2. Код лаунчера и ВСЕ новые функции — только Rust. Исключения: `site/` (HTML/CSS/JS без сборщиков и библиотек) и `.bat`.
   Python допустим лишь как одноразовый скрипт вне проекта.
3. Интерфейс и ответы — на русском. Дизайн — чёрно-белый, стеклянные полупрозрачные элементы, кнопки прозрачные с видимым текстом без сплошной заливки; допустимы только зелёный (одна сеть/готово) и красный (ошибки).
4. Первая строка ответа — суть. Без вступлений и без лести.

## 1. Скиллы
- В Antigravity скилл «вызывается» так: открой `.agent/skills/<имя>/SKILL.md`, прочитай целиком и следуй ему.
  Папки `reference/`, `scripts/` рядом с ним читай по ссылкам из SKILL.md. Не пересказывай по памяти.
- Подбор по типу задачи (минимум):
  - интерфейс лаунчера → `impeccable` (clarify/animate/polish/harden) + один из `ui-ux-pro-max`, `web-interface-guidelines`, `taste-skill`; тексты — workflow `/tov`;
  - сайт → минимум два из `impeccable`, `taste-skill`, `redesign-skill`, `ui-ux-pro-max`, `web-interface-guidelines`, `design-system`; тексты — `copywriting` + `/tov`; потом `/ui-audit` и `/live`;
  - скорость → `investigate-first` (сначала замер и причина, цифры «до/после»);
  - новая функция → `lean-build` (больше одного файла — `/ecc-plan`); баг → `investigate-first` → `surgical-patch`;
  - рефакторинг → `safe-refactor`; миграция данных/конфига → `migration`;
  - ввод пользователя, сеть, архивы, пути → `ecc-security-review`; новая чистая логика → `/ecc-tdd`;
  - поиск по коду → `caveman-explore`/`cavecrew`; ревью → `caveman-review` или `/ecc-code-review`;
  - видео → `remotion-best-practices` + `remotion-create`/`remotion-render`.
- Каждый нужный скилл читается отдельно. Нет скилла — одна строка пользователю и работа продолжается.

## 2. Проверка перед словом «готово»
1. `cargo check` без ошибок и новых предупреждений → `cargo test` (сейчас 57 проходят, 9 живых игнорируются).
2. `bash scripts/make-dist.sh` — пересобирает `Sad Launcher.exe` и установщик.
3. UI: скриншот затронутой вкладки. Сайт: открыть через `Запустить сайт.bat`, 375 px и 1440 px, консоль без ошибок.
4. **Всегда** дописать в `RRR.md` раздел «Обновление <дата>»: что изменено, какие грабли найдены.
5. Прогнать `verify-and-stop`. Без этого не писать «готово», «работает», «исправлено».
6. **Всегда** после проверок сделать `git commit` и `git push` в `main` сразу, без вопроса (секреты не коммитить).
7. **Выпуск версии** — если менялся код лаунчера (`src/`), агент САМ выпускает новую версию, не спрашивая: поднять patch в `Cargo.toml` (0.7.1 → 0.7.2), `bash scripts/make-dist.sh` (пишет `site/version.json` и установщик), commit + push в `main` — у пользователей при запуске появится «Обновиться». Только сайт/документы — версию не поднимать.

## 3. Запрещено
- Скиллы Caveman Cloud: `caveman-setup`, `caveman-discover`, `caveman-evidence-review`, `caveman-manage`, `caveman-optimize` (трафик через сторонний шлюз). Также `megacave`, `roblox-*`, `screenpipe-*`.
- Секреты (`.env`, токены, ключи CF) не читать, не печатать, не коммитить.
- Удаление чего-либо за пределами файлов, которые ты сам создал в этой задаче. Папку проекта и `%APPDATA%\Sad Launcher` не трогать.
- Консольные окна (всегда `CREATE_NO_WINDOW`), автозапуск/подключение без явного действия пользователя.
- Скриншоты с кликами, пока владелец играет в fullscreen: проверять логи и процессы.
